# 地铁线路图绘制器 · Subway Map Studio

在真实地图上布置车站、拖线连接，绘制自己的地铁线网，并模拟乘车导航。

## 功能

- 先确定车站位置，再从车站圆点拖线连接，支持新建线路、延长、闭环和撤销。
- 在线路上拖“＋”增加弯道，拖橙色圆点调形，双击圆点删除；拖回直线保留点，支持多点 S 形与左右翻转。
- 调整站序、线路颜色和站名位置，共走廊线路自动并排显示。
- 缩小时自动减少普通站名，保留换乘、端点、选中及手动定位站名；放大后恢复详细显示。
- 搜索起点和终点，按少换乘或少坐站规划路线。
- 模拟列车加速、匀速、减速，支持暂停、继续、重来、倍速和跟随。
- 中英双语报站：行驶时播下一站及换乘线路，到站切换到站提示，播完后再发车。
- 报站语速独立调节，提供 0.75×、1×、1.25×、1.5×、2×；可填写英文站名，留空使用离线拼音。
- 浏览器自动保存，支持 JSON 导入导出、SVG / PNG 导出和标准线路图生成。
- SVG / PNG 使用真实平滑曲线，标准图使用相切圆弧，放大后保持圆滑。

## 使用

在线使用：[GitHub Pages](https://ljnljn2005.github.io/subwaydrawer/)。网站无需安装，包含通用示例图纸；
你绘制的图纸保存在当前浏览器中，不会上传到 GitHub。请用 JSON 导出备份，再用 JSON 导入迁移到其他设备。
在线版不提供局域网存档接口。

下载或克隆整个仓库后，直接打开根目录的 `index.html`。请保留旁边的 `vendor/` 目录。
底图需要联网；选择“无底图（纯图纸）”即可只绘制线路图。语音报站需要浏览器支持系统语音。

也可以使用 Node.js 18 或以上版本启动本地服务，无需安装额外依赖：

```sh
npm run sync
npm start
```

打开 <http://127.0.0.1:8848/>。服务从 `dist/` 提供页面，修改源文件后需重新运行 `npm run sync`。
启动信息会显示局域网访问地址和存档口令。

在工具栏点击“导航”（快捷键 `R`），搜索并选择出发站与到达站，点击“开始模拟”。
勾选“中英报站”启用声音，在“报站语速”中调整语速；调整从下一段语音生效。
建好线路后，在线路属性里点击“调整曲线”，或切到选择工具（`V`）；“＋”始终贴在当前曲线上。
“翻到另一侧”只改变弯曲方向，“全部改直”移除当前线路的弯道点。
地图总览会先减少参与避让的站名，降低密集线网的计算量；车站圆点继续显示。
在设置中取消“缩小时减少普通站名”可显示全部站名。SVG / PNG 导出始终使用完整站名。

## 开发与检查

`index.html` 包含应用界面和逻辑，`server.mjs` 提供静态服务及局域网存档接口。
`scratch/` 保存维护脚本和回归检查，详细约定见 [HANDOFF.md](HANDOFF.md)。

```sh
npm run check
npm run test:link
npm run test:nav
npm run test:speech
npm run test:curve
npm run test:labels
npm run sync
npm run build:pages
```

用户存档 `saves/`、本地图纸 `dist/data/`、存档口令 `.archive-key` 与可重新生成的构建产物不纳入 Git。
Pages 部署只包含应用和 `vendor/` 资源；网页中编辑的图纸保存在使用者自己的浏览器里。
推送到 `main` 后，GitHub Actions 自动检查并发布；`npm run build:pages` 可在本地生成相同的 `.pages-site/` 内容。

Leaflet 与 pinyin-pro 使用本地副本；依赖的许可与来源说明保留在 `vendor/` 中。
